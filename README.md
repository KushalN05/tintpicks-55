# TintPicks

Welcome to TintPicks!

## Project Overview

TintPicks is a fashion utility app that helps you discover perfect color combinations for your wardrobe. It uses CIELAB color math to match the perfect shades of clothing.

## Tech Stack
- Frontend: React + TypeScript + Vite + TailwindCSS
- Backend: Supabase
- Components: shadcn/ui

## Getting Started

1. Install dependencies:
```sh
npm install
```

2. Run the development server:
```sh
npm run dev
```

3. Open `http://localhost:8080` in your browser.
